A pointer to groups already running. Not a booking platform. Past sessions stay listed, so a group can still be found after its date has passed.

01 · The idea

A calendar that refreshes every week.

Support groups run in cohorts of four to eight weekly sessions, so the useful view is what's starting this week, not a year of dates. This page lists upcoming meetups in date order, the way buildwith lists its Coming up section: date, place, type and a link out.

Each entry is tagged with the spell it's closest to. Occlumency covers naming feelings and the pause before a spiral. Legilimency covers reading what's left out in a relationship. The Foundation covers understanding from observation, for example ADHD and autism. Patronus covers memory work, such as grief.

Past sessions stay on the page, so a group that has already met can still be found.
