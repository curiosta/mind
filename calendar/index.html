Calendar.

Meetups and cohorts where people talk about their healing journey. Not a booking platform — a pointer to groups already running.

01 · The idea

A calendar that refreshes every week.

Support groups run in cohorts — four to eight weekly sessions — so the useful view is what is starting this week, not a year of dates. This page lists upcoming meetups chronologically, the way buildwith lists its Coming up section: date, place, type, and a link out.

The archive matters too. Groups that have run since 2026 prove the practice is recurring, not a launch-week novelty. Past entries stay on the page so the calendar reads as a living record.
