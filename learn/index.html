How to learn

Judgment is the scarce skill.

When answers are free, learning means deciding what's worth knowing, then proving to yourself that you know it with the tool closed. Three small experiments first. The reading comes after.

01 · Chunking

Twelve letters, twice.

You'll see a row of letters for five seconds. Then they disappear and you type what you remember. Then we do it again.

Do this first

Round 1 of 2

Ready?

Same number of letters

Try it on paper: look at QZKTMPRWXHDL for five seconds, cover it and write it down. Then do the same with ATMUPIPINSMS.

Both rows had twelve letters. The second was really four things you already know: ATM, UPI, PIN, SMS. Working memory only holds a handful of items at once. A chunk is an idea pressed into a single slot, so the other slots are free for the next step.

That's what understanding buys you: room. Oakley's recipe for building a chunk is to focus, understand, then learn the context where it applies. A formula memorised without that context falls apart when the question is asked a different way. That's the exam you thought you'd prepared for.

02 · The closed-tool rule

Which would you type?

Do this first

You have a chapter on photosynthesis to learn tonight, and a chatbot open. Pick the prompt you'd actually type.

Be honest. Nobody's watching.

The first prompt gets you a fluent paragraph, like the one on the home page. It leaves you feeling you know it, and that feeling is recognition. The second prompt makes you retrieve, and that's the part that builds memory.

The rule: use the tool to speed things up, never to stand in for you. Ask it for a question, not an essay. Then answer with the tool closed. If you can't explain the thing without it, you borrowed the explanation. Give it back.

03 · Focused, then diffuse

Leave a problem unfinished on purpose.

Focused mode works on a problem you already have a frame for. Diffuse mode links things you didn't mean to link. You can't be in both at once. The idea that turns up in the shower only comes if focused work left an unfinished problem behind for diffuse mode to chew on.

A timer, if you want one

25:00

Focused: 25 minutes. Phone face down.

Set any timer for 25 minutes. When it rings, write the question you're stuck on, then walk for five minutes without a feed.

04 · Where to learn

Don't start with another feed.

Start with a course, a book, or a person who'll ask you to rebuild the argument. Those still work. A chat window is only a tutor if you close it and write. Barbara Oakley failed mathematics at school and later earned a doctorate in engineering. The useful part isn't the ending. It's that she treated difficulty as a problem of method, not of character.

If you want the sources this site stands on, start here, in this order:

  1. Coursera, Learning How to Learn, Oakley and Sejnowski. The lectures are short. Do the retrieval, not just the videos.
  2. Oakley, A Mind for Numbers. The same ideas on paper, so you can close it.
  3. Hutchinson, Concept Development Studies in Chemistry, Rice University. Free. The subject is chemistry, but the point is the order, and the order carries over to anything.

Oakley, in practice

Illusion of competence. Highlighting and rereading feel like study, but they're recognition. Close the book and write what you remember. The blank line is the lesson. Sleep on it, then retrieve again. Spacing it out beats one long sitting.

Sleep. Memory settles while you sleep. The Patronus test is built on that: write today, retrieve tomorrow.

05 · Build last

Hutchinson's order

  1. Foundation
  2. Question
  3. Observations
  4. Deduction
  5. Model

He says the collection is meant to "redirect the focus of learning." Students were being handed the model and asked to believe it, so he turned the order around: a foundation, then a question the foundation forces, then observations, then deductions, and finally a model that's allowed to be wrong.

Models aren't proved. They're retired when an observation won't fit. If all you can do is recite the model, you took the conclusion without earning it. You can feel this happen in the fifth spell.
